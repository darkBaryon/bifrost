# 工作台基础信息接口

EE公共外壳通过 `POST /api/console/bootstrap` 读取基础状态。该接口不要求 `Settings.View`，完整 `GET /api/config` 仍按原设置权限授权。普通版继续使用原配置接口。

## 请求与认证

```http
POST /api/console/bootstrap
Content-Type: application/json
Origin: https://console.example.com
Cookie: ee_session=<个人会话>

{}
```

只接受有效且账号启用的个人会话；未分配角色、没有设置权限或仍需初次改密的有效会话均可调用。此规则只适用于基础状态，不改变其他接口的强制改密或权限限制。旧共享管理员Cookie、临时令牌、虚拟密钥及Basic/Bearer不能替代个人会话；非空Authorization头一律拒绝，即使同时带有有效Cookie。

Origin必须与部署的 `EE_PUBLIC_ORIGIN` 完全一致。没有Origin时可用同源Referer；两者冲突、来源不匹配或均缺失返回403。读取型POST也检查来源。

请求必须是严格JSON空对象，允许空白和 `application/json` 媒体类型参数。正文上限16KiB，拒绝空正文、null、数组、非UTF-8、未知字段、重复键、多份JSON和超限正文。按来源、Authorization、会话、JSON、宿主状态的顺序处理。

## 成功响应

```json
{
  "is_db_connected": true,
  "is_logs_connected": true,
  "env_label": "测试环境",
  "restart_required": { "required": true }
}
```

| 字段 | 类型 | 语义 |
|---|---|---|
| is_db_connected | boolean | 宿主配置存储对象是否存在，与原配置接口一致；不代表主动数据库健康探测 |
| is_logs_connected | boolean | 宿主日志存储对象是否存在 |
| env_label | string或null | 宿主环境标识；空字符串统一返回null，该键始终存在 |
| restart_required | 可选对象 | 读取到重启状态时返回，只含boolean字段required；false仍显式返回 |

重启状态不存在或读取失败时省略 `restart_required`，其余基础状态仍返回200。读取失败只在服务端记录固定原因 `restart_read_failed` 和request_id，不记录原始存储错误。响应不返回重启reason、管理员、认证配置、代理、连接串或其他完整设置。

## 错误与缓存

所有成功及错误响应均含 `Cache-Control: no-store`。服务端生成 `X-Request-ID`，用于关联访问日志与安全诊断。

错误格式沿用[账号认证接口](账号认证接口.md)：

```json
{"error":{"code":"unauthorized","message":"unauthorized"}}
```

| 状态 | code | 原因 |
|---|---|---|
| 400 | invalid_input | 正文或媒体类型不合法 |
| 401 | unauthorized | 无个人会话、会话失效/撤销、账号停用，或携带非空Authorization |
| 403 | forbidden | 来源缺失、不匹配或冲突 |
| 503 | unavailable | 身份存储读取故障，或宿主/宿主Config尚未提供 |

只登记精确POST路径；错误方法和近似路径由既有根路由保护拒绝，不因此获得认证旁路。
