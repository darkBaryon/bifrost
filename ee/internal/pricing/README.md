# 国内定价

根包只依赖标准库与已有的 google/uuid，负责国内官网价格及规则；宿主与存储类型留在适配包。

| 文件 | 职责 |
|---|---|
| `model.go` | 无 JSON/数据库标签的价格业务模型与币种、取价口径 |
| `pricefile.go` | 独立 JSON DTO、嵌入文件、解析及整份校验 |
| `pricefile_test.go` | 文件契约与非法输入测试 |
| `data/cn-prices.json` | 随版本发布的价格目录；2026-09-13 官网核对，收录情况见使用说明 |
| `vendors.go` / `vendors_test.go` | 官方域名匹配、手工映射优先和原始厂商名保留 |
| `overrides.go` / `overrides_test.go` | 美元/token 换算、UUID v5 与精确匹配覆盖 |
| `sync.go` / `sync_test.go` | 启动同步、所有权核验、逐行幂等与失败测试 |
| `persistence/` | 上游 ConfigStore / ModelCatalog 适配，依赖方向指向本根包 |

## 取价规则

文件头固定 `pricing_rule: lowest-tier-standard-rate`，按方案 v2 §9 的 A1 裁定：

- 输入长度取最低档；最低输入档内再按输出长度分档时，取最低输出档。
- 思考/非思考有不同价格时取非思考价；只有思考模式的模型取其唯一价。每条 `note` 记未取的思考价与其他阶梯价。
- 分时段取标准（高峰）价；限时折扣、Batch 折扣、赠送额度不取；真正免费模型填 0。每条 `note` 记未取的优惠。
- 缓存只有一种命中价时直接填；分显式/隐式时取自动生效的隐式命中价，显式命中及创建价不填，`note` 记未取比例。官网未公开、仅控制台显示的缓存价不填 `cache_read_input_cost`，不得按通用比例推算。未明确列出的快照不沿用别名缓存价。
- 在售以官网模型概览/模型列表的可用标注核实，历史价格行不能单独证明在售；不收预览与下线版。名单和公开价目交叉核对，疑点与未收录项见核对记录。
- Kimi 动态页读不到时仅收录官网静态内容能核实价格的模型；其余跳过并记实施偏差，不引入浏览器自动化。

这是单价近似：长上下文、较长输出子档和较贵的思考请求可能少算；折扣时段或活动价请求可能多算。它不等于厂商实际账单。输入/输出/缓存字段保存官网币种的每百万 token 价格，导入时统一换成美元/token。

## 同步边界

`New` 显式注入窄接口，`Sync` 先识别自定义厂商，再生成 provider 作用域的精确匹配覆盖，差量持久化成功后增量更新内存目录。UUID v5 与 `ee-pricing: ` 前缀同时核验所有权；手工行不改，前缀伪装只 warn。创建冲突转 Update，删除缺行视为成功，其他存储错误中止当次同步。

业务配置错误包装 `ErrConfig`，由 app 拒启；文件无效跳过同步，存储/目录错误记录后继续启动。模块不拥有数据库/宿主生命周期，也不做在线拉价和运行期监听。环境变量、运维、回滚与近似误差见[使用说明](../../docs/国内定价.md)。

嵌入 JSON 超过 500 行是逐模型来源与核对数据，不是业务代码；按方案 §5 保留单一完整数据文件，避免分片合并改变外部替换文件契约。
