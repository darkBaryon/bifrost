# 共享数据库事务与诊断

`write.go` 负责控制台事务和 SQLite 锁冲突重试。新模块调用 `Write` 打开事务，将同一个 `*gorm.DB` 传给参与操作的服务；各模块 Store 只绑定这个事务，不另开事务。

写锁暂沿用 `ee_identity_state` 的单例行，与迁移中的账号和角色模块共用。这里不放账号、会话、权限等业务判断。

`diagnostics.go` 提供入口操作上下文和最小日志接口。`WithOperation` 创建的操作名称及关联 ID 随同一上下文跨模块传递；`LogFailure` 只输出固定组件、阶段和安全驱动分类，不输出 SQL、凭据或驱动错误原文。各业务模块先排除正常业务拒绝，事务拥有方在整笔重试结束后记录最终故障并转换安全错误。

`write_test.go` 用真实 SQLite 验证中途锁冲突时整笔事务回滚并重试，不能留下第一次写入或锁计数。
