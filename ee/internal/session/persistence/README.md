# 会话存储

在调用方已有事务中维护会话与一次性票据。数据库连接由宿主管理；SQL 日志保持静默，避免凭据摘要进入驱动日志。

| 文件 | 职责 |
|---|---|
| [store.go](store.go) | 事务绑定、撤销、关联删除、到期清理和票据原子消费 |
| [rows.go](rows.go) | 已有会话与票据表的运行期行结构 |
| [lifecycle_test.go](lifecycle_test.go) | SQLite 会话和票据的事务边界、重复消费、关联删除及原始故障保留 |
| [cleanup_test.go](cleanup_test.go) | 两张表独立清理、撤销和消费记录保留、清理回滚与过期边界 |

原始 Store 不允许写入；绑定事务时创建独立副本，不能把事务写回共享 Store。空事务直接拒绝，不使用原始连接。底层故障经会话服务原样交回事务拥有方，由其完成重试、诊断，再转换为安全错误。

表由已有身份迁移创建，不能在这里重复迁移或改变既有迁移编号。票据只在条件更新影响一行时算消费成功；会话验证与授权由调用方继续在当前事务执行。
