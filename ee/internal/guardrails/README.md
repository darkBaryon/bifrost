# 本地内容安全框架

自有网关推理链此前没有可注入的本地内容检查。本包让调用方按输入/输出阶段运行检测，并按明确策略放行、拦截或仅记录。实际检测算法、配置管理和生产注册尚未接入，网关尚未因此开启防护。

参考 [Higress 源码研究](../../../product/需求/内容安全/Higress源码研究.md)的职责拆分、阈值判断和处置流程；Bifrost 是本项目内嵌的网关，本包通过其插件钩子接入推理链。

## 文件与调用链

```text
Bifrost 插件链
  → plugin/plugin.go：前后置钩子、错误短路及安全事件日志
    → plugin/text.go：提取全部历史消息或逐个候选回答的有界纯文本
    → engine.go：保存规则快照，按阶段、顺序及阈值运行检测
      → 注入的 Detector：执行具体算法
    ← engine.go：按显式策略决定处置
  ← plugin/plugin.go：放行或返回安全错误，禁止回退到其他模型重试
model.go：上述流程共用的检测契约、规则、结果、事件及错误码
```

## 检测契约

- 根包只依赖标准库。构造时注入规则、检测器注册表及完整文本字节上限；D1/D3/D4/D5 常量不代表算法已实现。
- `Check` 按顺序检查完整 UTF-8 文本；达到阈值才命中，观察继续，阻断停止。空文本仍送检，空规则不执行检测。
- 每条规则明确超时、命中动作和失败动作。检测器失败按规则允许或阻断；取消、非法输入和超限返回框架错误，此时结果恒为阻断，并保留此前已完成的事件。
- 检测在调用方同步执行，框架不另起 goroutine；不响应取消的检测器会在超时后继续阻塞调用方。实现必须并发安全、响应 context 取消。父请求超时也属于取消；检测器报告的超时属于检测失败。
- 规则和注册表复制，检测器实例不复制，生命周期归装配方。事件及日志不保存正文、命中原文或检测器异常文本。

## 接入前提

`plugin.New(engine, options, logger)` 构造插件；调用方提供可用的日志实例，明确错误状态码（400–599）及拦截文案。当前没有在 `app` 中注册空策略或测试检测器。

- 输入检查全部历史纯文本；非流式输出逐个检查候选回答，所有候选共享总字节预算。
- 未覆盖的内容明确拒绝：未经规范化的原始正文、未知参数、工具、图像或音频、推理正文、消息名称、停止文本，以及词元概率（包含模型生成的词及候选词）。推理强度、缓存时效等控制参数不作为正文送检。
- 宿主为超大请求或响应开启的原样透传模式不支持。即使只配置了大响应阈值，也会拒绝：宿主可能在调用模型之后才切换为透传，安全检查来不及介入。
- 开启输出检查时拒绝流式请求；仅输入检查允许规范化 Chat 流式请求。
- 上游错误原样保留，不审核其正文。

生产装配必须满足：安全插件排在可能短路返回响应的插件之前；其他插件、缓存或旁路不得在检查完成后改写受检正文。当前测试只覆盖独立钩子及安全插件包住模型替身的 Bifrost 管线，任意插件组合仍须在实际装配时验证。

验证：在 `ee/` 执行 `GOWORK=off go test -race ./internal/guardrails/...`。同名测试覆盖引擎与钩子；`plugin/schema_test.go` 提醒上游字段变化后的复审，`plugin/integration_test.go` 使用真实插件管线和测试替身，不调用外部服务。
