# 登录认证

本模块验证登录凭据和请求身份，不处理账号修改、角色权限或 WebSocket 票据授权。受限会话仍可通过身份验证，由具体业务决定是否要求先改密码。

| 文件 | 职责 |
|---|---|
| `service.go` | 登录预占、事务外密码比较、事务内复核与签发、登出 |
| `validation.go` | Cookie 和长连接身份验证、事务内复验、本人资料 |
| `model.go` | 认证所需账号资料、联合记录、普通 Store 接口及错误 |
| `passwords.go` | 所有密码操作共享的四槽计算限制 |
| [http/](http/README.md) | 登录、退出、本人资料、登录状态、票据和 BF 兼容路由，以及 Cookie/同源规则 |
| `hasher/` | bcrypt 算法和完整摘要检查 |
| `persistence/` | 旧账号/会话表的联合查询、登录桶、最近登录时间和安全诊断 |

登录先提交限流预占，密码比较不占数据库事务；随后在同一事务中复核账号版本、创建会话并更新最近登录时间。任一步失败不返回新 token。SQL 写入必须绑定调用方事务，不能自行提交或退回主连接。

装配方显式注入日志。限流预占、登录和登出的事务最终故障由服务在重试结束后记录，包括开启事务、加锁和提交失败；故障关联信息沿用入口传入的 database 操作上下文，正常业务拒绝不记为数据库故障。

账号和会话必须一次联合读取，不能改为两次无约束查询。表名、token 摘要、登录桶键和窗口保持既有数据兼容。装配方让登录、账号建号和改密共享同一个 `Passwords`，不要为每条业务另建计算槽。本模块借用数据库和会话服务，不负责关闭它们。

`validation_test.go` 验证身份与会话判定，`transaction_test.go` 验证事务内保留可重试错误、公开入口隐藏驱动错误，`passwords_test.go` 验证共享密码计算上限。真实登录事务回归在 `persistence/service_test.go`。
