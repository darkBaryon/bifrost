# 认证 HTTP 入口

负责登录、登出、当前登录状态与本人资料接口，并把 WebSocket 票据请求交给装配时传入的业务入口。账号创建、删除与密码管理的接口由账号模块注册。

| 文件 | 职责 |
| --- | --- |
| `handler.go` | 路由注册、请求诊断、同源与会话检查；新旧路径分别注册 |
| `endpoints.go` | 解码认证请求，调用业务入口并写入响应 |
| `dto.go` | 请求与响应字段，以及账号资料的安全投影 |
| `browser.go` | 部署来源校验、同源判断、当前与旧版 Cookie 处理 |
| `errors.go` | 认证和会话业务错误的 HTTP 映射 |
| `*_test.go` | 注册职责、JSON 字段、浏览器协议和请求边界的兼容检查 |

HTTP 路径保留现有 `/api/identity/*` 和 BF 的四条 `/api/session/*` 别名；路径兼容不决定代码归属。只有旧版登出和票据接口允许空正文。登录令牌只通过 HttpOnly Cookie 交付，响应 DTO 不包含令牌或凭据。部署来源取显式配置，不从代理头推断；初始化状态只通过注入的查询读取。

严格 JSON、请求关联 ID 与通用响应使用 `httpx`；同源和 Cookie 使用本包的 `Browser`，其他入口复用同一实例。
