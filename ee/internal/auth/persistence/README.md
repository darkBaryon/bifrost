# 认证 SQL

`store.go` 提供联合认证读取及登录相关写入，`rows.go` 保持现有表的列映射，`diagnostics.go` 排除业务拒绝后调用 database 的共用日志函数，保留入口上下文的操作名和关联 ID，只记录固定操作阶段与安全故障分类。

账号、会话和登录桶继续使用 `ee_identity_*` 表；本包不重新迁移已有数据库。认证联合读取使用一个 JOIN，账号资料仅更新最近登录时间和记录更新时间。限流预占由上层开启并锁定账号状态的事务包围，任一桶超限必须整笔回滚。

`WithTx` 创建存储副本，不修改共享连接。未绑定事务禁止写入；SQL 日志关闭，宿主错误日志也不输出 SQL、凭据或驱动原文。
