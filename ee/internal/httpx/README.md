# 控制台 HTTP 公共协议

本包提供多个业务 HTTP 入口共同使用的 JSON 边界和诊断上下文。登录、账号与权限服务仍由各自的 HTTP 入口调用；本包不认识业务模块。

| 文件 | 职责 |
| --- | --- |
| `decode.go` | 严格对象解码，以及旧会话接口显式选择的空正文兼容。 |
| `response.go` | JSON 响应、公开错误码与 HTTP 状态映射。 |
| `context.go` | 为请求、响应和数据库诊断分配同一关联 ID。 |
| `decode_test.go` | 正文、媒体类型、重复键、未知字段及嵌套深度边界。 |
| `response_test.go` | 错误白名单、敏感错误隔离与序列化失败契约。 |
| `context_test.go` | 诊断上下文与请求、响应头关联一致性。 |

业务 HTTP 入口须先把已识别的业务错误转换为本包的错误码；直接传入底层错误只会输出 `unavailable`。限流重试时间由业务模块设置。严格解码限制为 16 KiB；仅校验原始 JSON 结构的入口须自行限制正文大小和检查媒体类型。
