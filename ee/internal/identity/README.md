# 账号认证

管理本地账号、密码、会话和密码操作记录。登录身份与推理VK独立；本期主管理员可管理全局，成员仅访问本人能力。

- `model.go`：业务类型、错误、事务存储接口和可替换的账号管理策略。
- `service.go`：初始化、旧账号迁移、登录与撤销、改密、启停、重置幂等及事件查询。
- `http/`：Cookie、来源检查与接口适配。
- `persistence/`：共享数据库上的迁移和原子操作。

服务决定事务内容，适配实现事务；业务层不依赖HTTP、GORM或全局宿主。原始Token只在签发时返回给Cookie适配，库内存哈希；更改密码与撤销会话及操作事件必须一起提交。
