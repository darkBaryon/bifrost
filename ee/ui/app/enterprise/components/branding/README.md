# 品牌设置页面

## 功能

提供 Logo 和选填小图标的选择、移除、预览、保存及恢复默认操作。选择图片先改变草稿，保存后才更新配置；恢复默认经过确认后立即生效。

## 架构

`brandingView.tsx` 组合上传控件、预览和操作按钮；`useBrandingForm.ts` 管理草稿、异步操作和错误提示。上传控件通过回调交给表单处理，不直接请求接口。文件名随有效草稿保留，保存后显示“已设置图片”，移除后显示“未选择图片”；隐藏的原生文件输入会清空，以便再次选择同一文件。

选择文件时，先使用[表单校验规则](../../lib/schemas/README.md)检查大小和类型，再由 `image.ts` 读取、解码并检查像素尺寸。结果作为 Data URI 用于草稿预览和提交。

读取、保存和重置复用现有 [brandingApi](../../../../../../ui/lib/store/apis/brandingApi.ts)。保存或重置成功后更新查询缓存并清空草稿；失败时保留选择，要求重新读取配置后再操作。页面卸载或选择变化后，旧的读图结果不会覆盖当前草稿。任一位置有图片校验错误时禁止保存，仍允许重新选择或移除该位置；没有旧图时也可通过移除清除错误。

页面样式与其他设置页保持一致：标题通过 `PageTitle` 提升到顶栏，分节标题、卡片边框、按钮尺寸沿用上游设置页的写法，不引入独立样式文件。`ui/app/globals.css` 使用 `@source "../../ee/ui/app/enterprise"` 显式扫描自有源码目录，不依赖覆盖层的忽略规则或符号链接扫描行为。

预览复用 [useBranding 中的图片回退规则](../../../../../../ui/lib/hooks/useBranding.ts)；小图标为空时沿用 Logo。登录页和侧栏的实际品牌展示由该共享 hook 处理，本目录负责编辑页面。

## 文件说明

| 文件                                       | 职责                                                                                                                                          |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| [brandingView.tsx](brandingView.tsx)       | 组合页面，标题交给顶栏（PageTitle），展示加载与错误状态、表单、预览和恢复默认确认框。                                                         |
| [useBrandingForm.ts](useBrandingForm.ts)   | 管理草稿、选图、移除、保存、重置、重新读取及查询缓存更新。                                                                                    |
| [brandingUpload.tsx](brandingUpload.tsx)   | 渲染单个图片位置的缩略图、文件选择、文件名、移除按钮、限制说明和字段错误。                                                                    |
| [brandingPreview.tsx](brandingPreview.tsx) | 展示登录页及展开、折叠侧栏在浅色和深色背景下的图片效果。                                                                                      |
| [image.ts](image.ts)                       | 使用 FileReader 和 Image 读取本地图片，检查像素尺寸并返回 Data URI；提交前剥离前缀只送 Base64，避免无类型文件的 octet-stream 头被服务端拒绝。 |
| [image.test.ts](image.test.ts)             | 用浏览器 API 替身验证图片读取、解码失败及尺寸边界，不代替浏览器上传验收。                                                                     |
