# 任务记录(Cases)

按 Playbook 的 Change 模型,每个开发/重构/测试任务在这里留档。**结论必须绑定精确基线;修订保留历史,不覆盖旧结论。**

## 目录约定

```
cases/YYYYMMDD-<slug>/
├── requirement.md   # 需求:来源/目标/非目标/基线/风险档位(templates/development/requirement.md)
├── plan.md          # 方案:接口/数据/步骤/验收口径(Gate 1 前完成)
├── review.md        # 复核:对照方案检查实际 diff
└── acceptance.md    # 验收:证据 + Gate 2 放行记录
```

模板从 [playbook/templates/](../playbook/templates/) 复制;轻量任务可合并为单文件,但四个事实不可省:**目标、精确基线、验证证据、用户放行**。
