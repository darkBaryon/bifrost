# 08 · 部署与运维

## 快速体验

```bash
npx -y @maximhq/bifrost              # 下载预编译二进制并运行
docker run -p 8080:8080 maximhq/bifrost
```

控制台与 API 都在 `http://localhost:8080`。配置目录通过 `-app-dir` 指定（默认取操作系统配置目录），其中 `config/config.json` 遵循 `transports/config.schema.json`。

## Helm（Kubernetes）

`helm-charts/bifrost/`（已发布到 Artifact Hub）：

- 完整的 `values.yaml` + `values.schema.json` 校验；Deployment/StatefulSet 模板；可选捆绑 PostgreSQL 与 Qdrant。
- `values-examples/` 约 15 种现成组合：仅 SQLite、仅 Postgres、Postgres+Redis、SQLite/Postgres + Qdrant 或 Weaviate、外部 Postgres、生产高可用（production-ha）、从 K8s Secret 注入密钥、预置 Provider 与虚拟 Key、混合后端等。
- 附安装/校验/生成 values 的脚本。

## Terraform（多云）

`terraform/modules/bifrost` 一个模块通吃四类目标，用 `cloud_provider` + `service` 变量选择：

- AWS：ECS 或 EKS
- GCP：GKE 或 Cloud Run
- Azure：AKS 或 ACI
- 通用 Kubernetes

配置既可直接给 `config.json` 文件，也可用 TF 变量拼装（Provider、配置存储等）。`terraform/examples/` 有 aws-ecs、gcp-gke、azure-aks、kubernetes 四个可跑示例。

## recipes/ —— make 一键部署

根 Makefile include 了 `recipes/*.mk`：

```bash
make deploy-to-fly-io APP_NAME=my-bifrost   # Fly.io
# 另有 ECS 部署、本地 Kubernetes（recipes/values-local-k8s.yaml）
```

## examples/ —— 参考配置库

- `configs/`：约 20 份 `config.json` 样例（SQLite/Postgres/ClickHouse 存储、无存储、鉴权、MCP 引导认证、动态插件、nginx 反代、大负载、本地定价文件……）
- `dockers/`：docker-compose 组合栈
- `k8s/`：K8s 清单（含企业版与治理限流示例）
- `plugins/`、`mcps/`、`webhooks/`：插件模板、约 12 个测试 MCP 服务器、webhook 接收器

## 运维要点

- **可观测**：`/metrics`（Prometheus，telemetry 插件）；OTel 导出（otel 插件）；`/ws` 控制台实时事件；日志库支持保留期自动清理与物化视图聚合。
- **存储选型**：单机默认 SQLite 零依赖；生产建议 Postgres（配置）+ Postgres/ClickHouse（日志）+ 向量库（语义缓存需要时）。大日志负载可开启混合模式卸载到 S3/GCS。
- **多节点**：功能开关与模型目录同步支持集群 gossip；Prometheus 可切 Push Gateway 模式；企业版另有完整集群/边缘能力。
- **优雅停机**：SIGINT/SIGTERM 后 30 秒排空窗口。
- **健康检查**：`handlers/health.go` 提供健康端点（K8s 探针可用）。
