# D3 密钥格式核实

> 2026-09-17。D3 采用 Gitleaks 规则数据并自写扫描逻辑（见[调研总结](调研总结.md)），本文核实需要补充或修正的厂商格式。对照基线 Gitleaks v8.30.1（222 条规则）。
> 官方大多只写前缀、不写长度。下表长度凡未注明官方，均来自开源扫描器（TruffleHog、betterleaks、Kingfisher、osv-scalibr），写规则前需用真实 key 形态校准。未使用任何真实密钥。

## 一、必须处理的四件事

1. **Gitleaks 三处跟不上官方**（前两条已用假样本本机验证会漏）：
   - Gemini 只认旧的 `AIza`，漏掉 2026-05-28 起默认发放的 `AQ.Ab8R…` 新 key；
   - Anthropic 漏掉官方列出的 `sk-ant-api01-`；
   - OpenAI 规则把长度与 `T3BlbkFJ` 标记写死，建议放宽为不定长。
2. **裸 `sk-` 无法归属厂商**：DeepSeek、百炼通用 key、Kimi、硅基流动、混元、OpenCode 都是 `sk-` 开头，官方均未公布长度，第三方长度互相重叠（DeepSeek 的 32 位十六进制整体落在百炼的 32 位字母数字内）。统一按“`sk-` 类密钥”识别即可，不影响拦截。
3. **Bifrost 自己的虚拟 key 是 `sk-bf-`**（`transports/bifrost-http/handlers/wsresponses.go`），需加白名单，否则用户提到自己的网关 key 会被拦。
4. **规则写“前缀 + 最小长度”，不要写死位数**：腾讯云临时 ID 约 68 位且含 `-_`，阿里云旧格式可能是 16 位，按固定位数都会漏。

## 二、可写专用规则

| 来源 | 厂商与格式 |
|---|---|
| 国外模型 | Groq `gsk_`+52；Cerebras `csk-`+48；OpenRouter `sk-or-v1-`+64 hex；xAI `xai-`+80（管理 key `xai-token-`）；Replicate `r8_` 共 40（官方明写）；Gemini 新版 `AQ.Ab8R`+46；Azure OpenAI 新版 84 位含 `JQQJ99`/`ACOG` 标记（微软源码）；Anthropic 补 `sk-ant-[a-z]+\d{2}-` |
| 国内模型 | 百炼套餐 `sk-sp-`（官方明写）；MiniMax `sk-api-` 与 `sk-cp-`；千帆新版 `bce-v3/ALTAK-<21>/<40 hex>`；智谱 `<32 hex>.<16>` |
| 国内云 | 阿里云 `LTAI`、临时 `STS.` 与令牌 `CAIS`；腾讯云 `AKID`+32；火山引擎 `AKLT`、`AKTP`；百度新版 `ALTAK` |
| 办公平台 | 钉钉、飞书/Lark、企业微信的机器人 webhook，按完整 URL 识别最可靠 |

## 三、只能靠上下文或通用规则

需要配中英文字段名（AppSecret、corpsecret、SecretKey、access_key、密钥、密码、令牌、口令）才能识别，误报风险高：

- **国外**：Mistral（32 位字母数字）、Cohere（40 位）、Azure OpenAI 旧版（32 位 hex）、ElevenLabs（`sk_`，与 Sarvam、Stripe 冲突）、Fireworks（`fw_` 易撞标识符）、Runway（`key_` 过于通用）、OpenCode、Parasail、Wafer。Nebius 是 JWT，已被 Gitleaks 的 `jwt` 规则命中，但无法归属厂商。
- **国内**：华为云、七牛、京东云、又拍云、百度旧版、讯飞星火；钉钉 AppSecret 与加签 `SEC`、企业微信 corpsecret、微信 AppSecret、飞书 App Secret。
- **支付宝私钥**：官方 SDK 常写成不带 PEM 头的纯 base64，Gitleaks 的私钥规则依赖 `-----BEGIN`，查不出。

## 四、未找到格式

阶跃星辰、零一万物、百川（文档需申请）、Runware；以及钉钉 AppSecret、企业微信 corpsecret、微信 AppSecret 的长度。

## 五、其他事实

- Gitleaks 已覆盖且与现状一致：Databricks、HuggingFace、Perplexity、Cohere；Vertex 服务账号 JSON 由私钥规则覆盖（本机验证命中）。
- 现有扫描器几乎不覆盖国内办公平台：Gitleaks 国内只有阿里云两条，钉钉、企业微信、微信、支付宝均无；TruffleHog 等只有飞书/Lark。
- GitHub Secret Scanning 已收录 Groq、OpenRouter、xAI、Replicate、Mistral、Azure OpenAI、Gemini、DeepSeek、火山方舟、腾讯云、阿里云、百度等类型，但只公开类型名，不公开正则。
