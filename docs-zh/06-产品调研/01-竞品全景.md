# AI 网关竞品全景(2026-08 调研)

> 定位:toB AI 网关。本文按象限盘点所有相关产品,并标注 2026 年市场大事件。
> ⚠️ 信息源偏差警告:搜索结果中大量榜单出自厂商内容营销(getmaxim.ai / kosmoy / lunar / truefoundry 都在自卖自夸),结论需交叉验证。社区中立清单见 [awesome-ai-gateway](https://github.com/cuihuan/awesome-ai-gateway)(收录 160+ 网关,双语,含可复现基准)。

## 象限 A:独立开源网关(Bifrost 的直接对位)

| 产品 | 语言/许可 | 定位与差异点 |
|---|---|---|
| **LiteLLM**(BerriAI) | Python / MIT | **生态最大**,100+ Provider,虚拟密钥/预算齐全;弱点:Python GIL 限制吞吐,10-50ms 开销,OSS 版无语义缓存、无原生 MCP 网关 |
| **Bifrost**(Maxim) | Go / Apache-2.0 | 11µs 开销、原生 MCP 网关、分层治理、企业双轨;背靠 Maxim 评测平台 |
| **Portkey Gateway** | TS / MIT(2026-03 起 2.0 开源) | 治理+护栏+可观测开箱即用;母公司 **2026-05 被 Palo Alto Networks 收购**(安全巨头入场信号) |
| **Envoy AI Gateway** | Go+Envoy / Apache-2.0 | CNCF 正统,建在 Envoy Gateway 上;K8s 原生场景(llmaz 等推理平台在用);基建气质最重 |
| **Kong AI Gateway** | Lua+NGINX | 老牌 API 网关的 AI 插件扩展;已有 Kong mesh 的组织顺手启用,而非新系统 |
| **Higress**(阿里开源) | Go+Istio+Envoy / Apache-2.0 | 云原生 API 网关 + AI 能力(多模型负载均衡/Fallback/Token 限流/AI 缓存),Wasm 插件(Go/Rust/JS);国内生态锚点 |
| **One API / New API** | Go / MIT | 国内草根双雄:统一 OpenAI 格式转发 + 计费分发;New API 是 One API 的二开加强版(30+ 服务商,支持 Midjourney 等);个人/中小企业渗透率高,治理能力弱 |
| ~~TensorZero~~ | Rust | ⚰️ **2026-06 GitHub 归档,团队退还投资人资金**——网关+LLMOps 一体化路线阵亡样本 |

## 象限 B:托管 SaaS 网关(零运维换数据出境)

| 产品 | 定位 |
|---|---|
| **OpenRouter** | 模型聚合市场,"接触最多模型的最快方式";开发者心智占有率最高 |
| **Cloudflare AI Gateway** | 24 家原生 Provider,2026-05 加通用 REST 端点;贴边缘网络卖 |
| **Vercel AI Gateway** | 数百模型单端点+自动故障切换;绑 Next.js/Vercel 生态 |
| **Helicone** | ⚠️ 2026-03 **被 Mintlify 收购**,定位收缩为"配合其他网关的可观测层" |
| Requesty 等长尾 | 存在但声量小 |

## 象限 C:云厂商方案(单云生态内最顺滑)

| 厂商 | 方案 |
|---|---|
| 阿里云 | **AI 网关**(= Higress 企业版):多模型代理/Fallback/AI 安全/Token 计量计费 |
| Azure | API Management 的 GenAI Gateway 能力(绑 Azure OpenAI 参考架构) |
| AWS | Bedrock + API Gateway 组合模式(无独立 AI 网关产品) |
| Google | Apigee + Model Armor |
| 火山/腾讯/百度 | 均有类似托管形态(本轮未细查,待补) |

共同弱点:跨云/跨 Provider 场景乏力,而生产级 AI 架构普遍多供应商混用。

## 象限 D:企业治理型(toB 合规牌,与 Bifrost 企业版正面交锋)

| 产品 | 定位 |
|---|---|
| **Kosmoy** | LLM+MCP+Agent 三网关一体,护栏(毒性/PII/提示注入)+RBAC+会话审计 |
| **Lunar.dev** | ⚠️ **被 Boomi 收购**;自托管 VPC/离线部署/SOC2,管 LLM+MCP+API 全流量 |
| **TrueFoundry** | 主打超低延迟的企业级高吞吐部署 |
| Javelin、Prompt Security 类 | 安全侧切入的网关/代理,声量较小 |

## 2026 年市场大事记(整合之年)

- **2026-03**:Portkey Gateway 2.0 以 MIT 开源;Mintlify 收购 Helicone
- **2026-05**:Palo Alto Networks 收购 Portkey(安全巨头入局 AI 网关)
- **2026-06**:TensorZero 归档退场
- Boomi 收购 Lunar.dev(集成平台补 AI 治理)

**信号解读**:独立网关创业公司难以独活——要么被安全/平台巨头收编,要么背靠母公司输血(Bifrost 之于 Maxim,Higress 之于阿里)。开源+企业双轨 + 有母体造血,是活下来的公司的共同形态。

## Bifrost 的竞争坐标(初判,待深挖)

- **性能牌**:Go 11µs vs LiteLLM Python 10-50ms——对高并发 toB 场景是真差异
- **MCP 牌**:原生 MCP 网关是 2026 的关键筹码(Kosmoy/Lunar 都在打"LLM+MCP+Agent 全治理")
- **最直接的对手**:生态看 LiteLLM,企业治理看 Portkey(收编后有 PA 背书),云原生正统看 Envoy AI Gateway;国内看 Higress + New API
- **搜索信号**:getmaxim.ai 的 SEO 内容矩阵极其凶猛(搜任何"gateway 对比"都是它的软文)——市场声量战打得很积极
