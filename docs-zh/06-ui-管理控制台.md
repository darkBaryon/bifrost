# 06 · ui —— 管理控制台

`ui/` 是随网关一起发布的 Web 控制台（`http://localhost:8080`）。构建产物拷入 `transports/bifrost-http/ui/` 后嵌入 Go 二进制，因此**单个二进制 = API + 控制台**。

## 技术栈

React 19 + TypeScript + **Vite 8**，路由用 **TanStack Router**（文件式路由，自动生成 `app/routeTree.gen.ts`）；状态：Redux Toolkit + nuqs（URL 状态）；组件：Radix UI / shadcn 风格（`components/ui/`）+ Tailwind CSS 4；表格 TanStack Table；图表 Recharts；编辑器 Monaco；提示 sonner。代码检查用 oxlint/oxfmt。

> 注意：界面文案全部是硬编码英文，目前**没有 i18n/中文支持**（详见本文档系列的说明，需要中文只能用浏览器翻译）。

## 页面结构

顶层路由（`ui/app/`）：`login/`、`oauth/consent/`、`agent/handover/`、`pprof/`、`_fallbacks/enterprise/`（企业版页面的开源占位），主体在 `workspace/`。

### workspace 下的功能页面（30+ 个）

| 分类 | 页面目录 | 功能 |
|---|---|---|
| 总览 | `dashboard` | 用量/成本/延迟总览仪表盘 |
| 可观测 | `logs`、`observability`、`audit-logs` | LLM 请求日志、追踪、审计日志 |
| 模型接入 | `providers`、`model-catalog`、`model-limits`、`custom-pricing` | Provider 与 Key 管理、模型目录、模型限额、自定义定价 |
| 治理 | `virtual-keys`、`governance`、`rbac`、`scim`、`oauth-grants` | 虚拟 Key、团队/客户/预算/限流、权限、SCIM 用户同步、OAuth 授权 |
| 路由 | `routing-rules`、`adaptive-routing`、`complexity-router`、`circuit-breaker` | CEL 路由规则、自适应路由、复杂度分层路由、熔断器 |
| 告警 | `alerting`（rules/channels/history）、`webhooks` | 告警规则/通道/历史、出站 Webhook |
| 插件与护栏 | `plugins`、`guardrails` | 插件管理、内容护栏 |
| MCP | `mcp-registry`、`mcp-settings`、`mcp-sessions`、`mcp-logs`、`mcp-auth-config`、`mcp-tool-groups` | MCP 服务器注册、会话、日志、认证、工具分组 |
| Prompt/技能 | `prompt-repo`、`skills-repo` | Prompt 仓库（带版本）、技能仓库 |
| 集群 | `cluster`、`edge-control` | 集群节点、边缘控制（企业向） |
| 系统 | `config`（security/proxy/branding/license/client-settings/performance-tuning/compatibility）、`docs` | 系统配置、内嵌文档 |

## 与后端的交互

- 数据全部走 `/api/*` 管理接口；实时事件走 `GET /ws` WebSocket。
- E2E 测试依赖组件上的 `data-testid` 属性——改 UI 时必须保留/补充（AGENTS.md 明确要求）。

## 构建与开发

```bash
make dev          # UI dev server (localhost:3000) + API (8080)，API 会代理 UI
cd ui && npm run build   # 产物 out/ → 拷贝到 transports/bifrost-http/ui
```
