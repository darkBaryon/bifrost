## 摘要与起点

基线 `7ac06f8a13b8ed630830bae51b38dc2f54067ebc`，代码迁移开始前 EE Go 代码无未提交修改；此前产品、规范与权限工作文档的未提交修改保留。

从镜像上游的 transports/framework 目录迁到 cmd/internal，品牌增加业务服务与存储接口。依据 [EE 后端架构](../../../../product/架构/EE后端架构.md)，本次只迁移已有功能，不建空业务模块，不改变前端覆盖机制。

## 现状与调用方

- `ee/transports/bifrost-http/main.go` 调用 EE Bootstrap，后者装配品牌 Store/Handler、探针表/Handler/插件和全局标记。
- 品牌 Handler 直接依赖具体 Store，图片内容校验混在 HTTP 包；Store 同时声明业务输入与数据库模型。
- EE 路径的生产调用方为上述 Go 入口、`ee/Makefile`、UI schema 的校验说明；冒烟脚本使用 `ee/tmp/bifrost-http`，其中 OSS 对照入口仍为根 transports。
- 没有独立前端项目迁移；当前数据库、上游鉴权、Router、插件注册和生命周期均复用。

## 目标结构与接口范围

| 原位置 | 目标 |
|---|---|
| transports/bifrost-http/main.go、ui/ | cmd/bifrost-http/main.go、ui/（embed 产物） |
| server/bootstrap.go | internal/app/bootstrap.go：依赖装配与注册 |
| lib/shell.go、handlers/middlewares.go | internal/bifrost/：宿主 HTTP 接入 |
| 探针表、Handler、no-op 插件 | internal/bifrost/：现有宿主接入验证组件 |
| handlers/branding/ | internal/branding/http/：HTTP 解析与响应 |
| framework/configstore/branding/ | internal/branding/persistence/：表、迁移、事务读写 |
| 品牌模型、图片校验、操作规则 | internal/branding/：业务类型、Repository、Service |

业务包只依赖标准库；HTTP 和存储依赖业务包，app 注入具体实现。探针属于宿主集成验证，保留在 bifrost 适配包，不建立独立业务或额外服务层。

允许变更的 Go 内部接口：Bootstrap/Handler/Store 的 import 路径与包名；品牌新增 Settings、Asset、Patch、Repository、Service、ValidationError，Handler 改为接收 Service；数据库行留在 persistence。数据库 Reset 简化为服务调用原有原子 Update，原图片 hash 计算仍是存储字段派生。HTTP 负责 JSON、Base64/data URI 解码，服务负责图片格式、尺寸、MIME、空操作与当前资源选择规则。

对外保持：全部路由/方法、读取公开与写入上游鉴权、缺字段/空串/null 语义、响应字段与缓存、413/400/404/500 错误类别；`ee_branding`/`ee_probe` 表、字段、`ee_branding_v1`、迁移锁键、图片 hash、插件名及响应标记不变。品牌两图校验完成后才写入，保留局部更新与事务回滚。

## 实施与验证

1. 在旧路径跑现有 EE 测试，确认基线；保留一个由旧存储写入的临时 SQLite 数据库用于迁移前后比较。
2. 搬迁入口/宿主/品牌包并同步 imports、构建与 embed；抽出品牌业务服务和无 ORM 的业务类型，适配现有测试。
3. 为业务直接调用补充无效图片不写入、双图原子校验、资源版本选择等测试；用旧数据库核实新迁移不改变已有数据。
4. 运行 Go test/vet/build、构建 UI 并验证 embed、启动使用临时数据库的 EE 做路由/探针冒烟；同步包 README 与当前文档路径，执行预飞及独立代码/收敛评审。

主要风险是 import/embed 路径遗漏、三态输入改变和模型拆分影响表映射。接口/存储测试覆盖前两者，旧库兼容验证覆盖后者；PostgreSQL 专用锁测试需专用测试库，未配置则明确记录未执行。

## 回滚与范围

全部改动在当前功能分支工作树中完成；回滚仅恢复本次 EE 文件与引用，不覆盖此前文档修改。不更改上游实现、依赖版本、权限功能、数据结构或迁移版本，不操作已有服务和用户数据。

## Gate 决策结果

用户已明确授权按已确认架构迁移现有 EE；无新增业务/架构取舍、外部依赖或费用。方案复核通过后 Gate 1 自动继续。
