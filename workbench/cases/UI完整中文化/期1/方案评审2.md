**2.2(属性口径分裂)→ 已修复。**
v2 选了评审1 给出的第一条路:属性通道(:313,亲核确为 `DICT[v.trim()]` 直查)改走 translateRaw,与文本通道同管线;并补上了评审1 要求的六者对应论证——三 DOM 属性走属性通道、label/description/tooltip 等 React prop 渲染为文本节点走文本通道,scanner 统一按 translateRaw 全语义判定。论证成立(Radix/shadcn 形态下三 prop 确实落为文本节点)。残留一个挂载后更新的边缘缺口,不足以推翻修复,单列为新发现 N1。

**3.1(scanner 看不见动态句)→ 未修复(部分修复)。**
"看不见"这一半修了:第④类模板字面量提取 + 步骤2 输入改源,目标2 有米了。但"提取出来之后怎么判定已覆盖"这一半仍是悬空的,且按 v2 自己写下的机制推演,在它自己引用的样例上**必然失败**:

1. **对账算法未定义且朴素实现必不中。** §4 写"`${…}` 归一化为 `⟨n⟩`…与运行时同口径 RULES 试配"。亲核 `components/ui/providerConfigCard.tsx:186`:`` `${n} model budget${n === 1 ? "" : "s"}` `` ——归一化骨架为 `⟨n⟩ model budget⟨n⟩`(第二个占位符是复数后缀三元式,不是数字)。运行时规则必然写成 `/^(\d+) model budgets?$/` 之类,直接 `.test()` 骨架永远 false → 该条永挂清单 → `--check` 永红,唯一出路是塞白名单——把评审1-3.1 的"零证明力"从"看不见"翻转成"永远红/白名单放行",证据链同样不闭合。需在契约中写死对账算法(如:规则源码侧同步归一化;或 RULES 条目携带 scanner 侧骨架声明,self-test 断言声明与样例互证)。
2. **非数值插值撞自家禁令,无处置通道。** 亲核 `components/ui/multiSelect.tsx:614`:`` `${addedLabels[0]} selected. …` `` ——占位符是任意标签串,规则要覆盖它必须 `(.+)` 级捕获,而 §4/§8 明令禁止;DICT 装不下动态串。此类句子按需求口径本可白名单豁免,但方案必须写明这条处置通道及理由模板,否则清零目标与禁令互斥。
3. **第④类无提取围栏,误报洪水。** 实测扫描范围内含 `${` 的模板字面量 1356 行,含"空格+英文词"粗筛后仍 422 行(className/cn 上下文即占 113 行,另有 URL/key/id 拼接)。真实 UI 动态句估计仅数十条。无范围启发式则白名单需数百行且逐条附理由——不可行,并将实质性诱导宽正则白名单,与 4.2 护栏对冲。

以上三点同属"第④类的提取—判定—处置闭环",合并计 1 条阻断遗留。

**3.2(RULES 循环风险)→ 已修复。**
收敛契约①(结果===输入→null,对齐 :295 既有不变量)+ 契约②(译文禁留英文锚)+ self-test 固定点断言(translateRaw 全语义再入,同时覆盖"再命中 DICT"与"再命中任何规则")+ §8 入册,四件套齐了。残余风险仅剩非样例输入构成跨规则变形环,被契约②纪律压制且锚定 `^…$` 中文输出实际不可命中英文锚规则,可接受。

## 二、新发现问题

**N1 [建议] 属性挂载后更新不重翻,"scanner 与运行时一致"对属性不完全成立。**
位置:方案 §4 属性口径说明;`zhLocale.ts:336`(`observer.observe` 未开 `attributes: true`)。属性只在节点入树时翻一次;placeholder/title 随状态动态变化则残留英文。建议:observe 增加 `attributes: true, attributeFilter: ATTRS` 并在回调加属性分支(收敛契约①天然防属性回写环),或在 §6 盲区明示,二选一写进方案。

**N2 [建议] 对账自检的机械计数形态强耦合文件内容。**
`": "` 计数对当前文件精确成立,但未来键/值/正则/注释含该形态即误炸;`],` 计数同理。失败是响的(退出 1)可接受,建议改为行锚定计数降低误炸率。

**N3 [建议] "self-test 拒绝全匹配行"无可执行定义。**
"`/.*/`、`/.+/` 类"的"类"字不可执行,逃逸变体(`/^.*$/`、`/[\s\S]*/`)枚举不尽。建议语义级判定:白名单每条正则不得命中随机金丝雀串,命中即 self-test 失败;checklist 的形态 grep 降格为 tripwire。另:字面行含 `#` 与行内理由注释的解析冲突未定义,实现时补转义约定。
