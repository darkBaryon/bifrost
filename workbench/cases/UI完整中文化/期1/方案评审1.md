## 逐维度发现

### 维度1:需求覆盖

**1.1 [阻断] checklist 与方案第7节静默丢弃了需求验收口径中的 `npm run build` 成功**
checklist 仅落 tsc/self-test/--check 三条命令,build 无处核验;tsc 通过不等于构建通过。→ checklist 追加 ui-build,第7节改"五条"。

**1.2 [建议] 需求样例动态句的真实存在形态未经核对**
亲核:"keys found" 仅以静态串存在(`components/ui/entityAssociationSelect.tsx:78,83`,无数字变量);"Showing X of Y"/"N minutes ago" 字面量未检索到。→ 步骤1 对样例逐一定位源头,不存在者以真实句式替换并记录。

### 维度2:现状盘点比对

**2.1 盘点核对**:文件 344 行 ✓、DICT 252 ✓(需求写 ~270 与实际不符)、三处行号 ✓、起点 ✓、ui/scripts 不存在 ✓。

**2.2 [阻断] 盘点遗漏:属性翻译通道不走 translateRaw**
`zhLocale.ts:313` 属性直查 `DICT[v.trim()]`,不吃小写兜底也不吃 RULES;方案只改 translateRaw,属性动态句运行时永不翻译,而 scanner 按"命中 DICT(含兜底)或 RULES"判已覆盖——**scanner 判已覆盖、运行时不翻译,`--check` 空清单成为假证据**。另:scanner 提取六属性、运行时只翻三属性,对应关系未论证。→ 属性通道统一改走 translateRaw,或 scanner 对属性按运行时真实口径判定,二者必居其一。

### 维度3:接口设计

**3.1 [阻断] scanner 三类提取结构性看不见动态句**
本库动态句几乎全为 JSX 表达式内模板字面量(`providerConfigCard.tsx:186,203,208,326`、`toolCallView.tsx:532-533`、`multiSelect.tsx:614-619`、`logDetailView.tsx:2106`),三类提取一条都抓不到 → 清单里不会出现动态句,目标2"从清单提取规则"无米下锅,`--check` 对动态句零证明力。→ 增加第四类提取:模板字面量,`${…}` 归一化为占位符后与 RULES 做可命中性对账。

**3.2 [阻断] RULES 无收敛防护,存在 MutationObserver 无限循环风险**
既有 DICT 路径靠 `hit === trimmed → null`(:295)保证不重入;RULES 草图未定义"替换结果 === 原文"及"结果再命中规则"的行为——nodeValue 赋值必然再触发 characterData → 若规则输出仍可命中任何规则,页面死循环冻结。→ 契约补两条:结果===输入返回 null;self-test 固定点断言(每条规则的输出不得再命中任何规则),规则译文不得保留可再匹配的英文锚。

**3.3 [建议]** 顺扫无排序纪律与冲突检测 → 禁止 `(.+)` 级全泛化捕获;self-test 断言"样例恰好命中一条"。

**3.4 [建议]** 正则解析 zhLocale.ts 无对账自检,转义引号/注释/正则字面量都会静默少读 → self-test 对账断言:解析条数 == 机械 grep 计数,不一致退出 1。

### 维度4:checklist 一致性

**4.1** 已落三条与 preflight 四类检查实测兼容,链路成立;但缺 build(见 1.1),且 `--check` 证明力依赖 2.2/3.1 修复。

**4.2 [建议]** 白名单一条宽正则即可让 --check 变绿,零约束旁路 → checklist 增护栏(禁全匹配行),白名单终态逐条附理由进验收记录。

### 维度5:实施步骤与回滚

**5.1 [建议]** 步骤划分成立、回滚口径亲核属实;但步骤2 输入依赖 3.1 修复。
**5.2 [建议]** "侧边栏 21 入口"为未证实硬编码 → 巡检当日运行时实际枚举。

### 维度6:风险清单

**6.1 [建议]** 遗漏:RULES 循环风险(冻死级)、属性口径分裂、"性能可忽略"无量化(日志流式页高频 mutation) → 巡检增加流式页 CPU/掉帧观测点。

## 结论

**verdict:需修改**(阻断 4 条:1.1 / 2.2 / 3.1 / 3.2)。方案 v1 冻结,产出 v2。

## 一句话总评

盘点数字和行号经亲核几乎全对、步骤与回滚干净利落,但方案的核心承诺"--check 通过 = 全站覆盖有证据"在三处被自己的接口设计击穿——scanner 看不见动态句、属性通道不吃规则层、规则层没有收敛防护——证据链没闭合之前,这仍是一份"看起来可收敛"而非"可收敛"的方案。
