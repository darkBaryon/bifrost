## 给用户的摘要

现状:汉化 252 词条靠人工补,动态句(模板字面量)完全不翻,属性通道行为与文本通道不一致。
做完:一条命令列出全部未翻译文案;动态句"提取→判定→处置"三段闭环:规则携带骨架声明对账、规则做不了的走带理由白名单并记 Finding、1300+ 模板字面量有三重围栏防误报洪水。
拍板清单:①RULES 条目从二元组升为四字段对象(re/out/skeleton/sample)——多两个字段换来"scanner 判定=运行时行为"可机械互证 ②非数值插值(如 `${label} selected`)本期不翻,白名单豁免并记 Finding(DOM 层无安全译法,强翻要冒误吞风险)③属性观察升级(attributes: true),动态属性也能重翻。

**目标**:①覆盖率脚本(四类提取 + 三重围栏,`--check` 空清单退出 0)②RULES 规则层(四字段契约)统一服务文本+属性通道,属性支持挂载后重翻 ③字典/规则/白名单三通道收敛至清单清零 ④主要页面巡检通过(含日志流式页性能观测)

## 4. 接口与数据设计

**zhLocale.ts 增量**(唯一改动的既有文件,三处):

```ts
// ① RULES:四字段对象,skeleton/sample 供 scanner 与 self-test 机械互证(评审2-3.1.1)
type ZhRule = {
  re: RegExp;        // 锚定 ^…$;禁止 (.+) 级全泛化捕获;上限 100 条
  out: string;       // 译文模板($1..$9);不得保留可再匹配的英文锚
  skeleton: string;  // scanner 侧骨架声明:与"模板字面量归一化"(所有 ${…} → ⟨x⟩)完全同构
  sample: string;    // 自测样例:必须命中 re 且恰中此一条
};
const RULES: ZhRule[] = [
  { re: /^(\d+) model budgets?$/, out: "$1 个模型预算",
    skeleton: "⟨x⟩ model budget⟨x⟩", sample: "3 model budgets" },
  // 首批规则输入 = 步骤1 清单第④类;skeleton 全表唯一
];

// ② translateRaw:精确 DICT → 小写兜底 → RULES 顺扫首中即停
//    收敛契约:任何路径 结果===输入 → null;固定点断言强制"输出再入必 null"

// ③ walk 属性通道(:313)改走 translateRaw;
//    observer.observe 增加 attributes: true, attributeFilter: ATTRS,
//    回调加属性分支(契约①天然防属性回写环)(评审2-N1)
```

**新文件 `ui/scripts/zh-coverage.mjs`**(Node ≥20,零依赖,只读):

- 扫描范围:`app/ components/ hooks/ lib/` 的 .tsx/.ts,排除 `*.gen.ts`、`_fallbacks/`
- 四类提取:①JSX 文本节点 ②六属性/prop 字面量 ③`toast.*("…")` ④模板字面量
- **第④类围栏**(评审2-3.1.3 + 评审3-F1 修订):
  1. **位置围栏(四通道)**:JSX children 位置、六 prop 赋值、toast/announce 实参、**赋值/return 位置**(评审3-F1 修法①;第四通道须同时通过形态+上下文围栏,以评审2 的 422 行基数在步骤1 复测洪水可控性)
  2. **形态围栏**:归一化骨架须含 ≥2 个空格分隔的英文单词(排除标识符拼接)
  3. **上下文围栏**:排除判定以**模板自身语法位置**为准(仅当模板是 `className`/`cn(`/`clsx` 实参或 URL/`key=`/`id=` 值时排除,不按整行连坐;评审3-F3),self-test 含"单行同现 className 与 children 模板"负例
  4. **行级旁路报告**(评审3-F1 修法②,与①并用):任何"形态围栏内、仍被位置/上下文围栏排除"的行,输出**行级明细**随首份清单入库,人工一次性分流(规则/白名单/忽略)并入验收记录——聚合计数不可审,行级才可审
- **第④类判定**(评审2-3.1.1):模板字面量归一化(所有 `${…}` → `⟨x⟩`,不区分插值内容)后,骨架与某条 RULES 的 `skeleton` 声明**逐字符相等** → 已覆盖;否则进清单(标记"动态类")
- **非数值插值处置通道**(评审2-3.1.2):规则做不了的动态句 → 白名单豁免;**动态类白名单行匹配的是归一化骨架而非源文本**(评审3 补句);理由标签强制为 `[动态-非数值]` 或 `[动态-复杂结构]`,并登记 Finding(候选后续方案:元素级规则/上游 i18n PR);验收记录汇总此类清单
- 静态判定(①②③类):与运行时同口径——精确 DICT / 小写兜底 / RULES 试配(sample 语义)
- 字典/规则读取:正则解析 zhLocale.ts;对账自检改**行锚定计数**(DICT 块内 `^\s*"` 开头行数 == 解析条数;RULES 块内 `^\s*\{ re:` 行数 == 解析条数),不一致退出 1(评审2-N2)
- `--self-test` 断言集(≥14):四类提取各 ≥1 例;围栏三例(className 排除/单词数排除/位置排除);每条规则 sample **恰中该条**;**固定点:每条规则对 sample 的输出再入 translateRaw 必 null**;**互证(评审3-F2 定义写死):sample 必须是 skeleton 的代入实例——skeleton 字面段 regex 转义、`⟨x⟩` 展开为 `(.*?)`、加 `^$` 锚定后,sample 必须命中;且 sample 同时命中 re;两者同真才过**;白名单金丝雀(见下);对账例;**归一化嵌套花括号例(评审3-F4:`${fn({a:1})}` 类错切进清单,响的失败,不得静默)**
- `--check`:清单非空退出 1

**新文件 `ui/scripts/zh-coverage-whitelist.txt`**:

- 行格式:`字面文本` 或 `/regex/`,可跟 ` # 理由`;字面文本含 `#` 须转义 `\#`(评审2-N3)
- **金丝雀判定**(评审2-N3,主防线):每条 `/regex/` 不得命中金丝雀串 `"XQ7#鑫W9-zk"`,命中即 self-test 失败;checklist 的形态 grep 降为 tripwire
- 终态逐条附理由,进验收记录
