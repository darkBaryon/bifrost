## 结论

**需修改**(差量小,v3 只需改两处)。上轮 B1-B3 与 S1-S11 均已落实,「相对 v1 的变化」声明属实;新增的 `/api/branding`、ShellRewriter、checklist 三条改动亲核成立。剩下两条是 v2 新写进合同里的事实性错误,不改会直接让冒烟/Makefile 失败:

1. **B1 §4.3 workspace 目标的幂等命令在任何 cwd 下都不成立**。原文 `grep -qxE '\s*\./ee' ../go.work || go work use ./ee`「在仓库根」:在仓库根 `../go.work` 指向仓库外;在 ee/ 下(`make -C ee` 的 cwd)`go work use ./ee` 报 `go: directory ee does not exist`(临时工作区实测)。而 dev/build/smoke 全部依赖该目标。改法:`cd .. && (grep -qxE '\s*\./ee' go.work || go work use ./ee)`(实测幂等、二次执行不重复)。
2. **B2 §6 两条冒烟断言与事实不符**。
   - T6「OSS 对照返回 404」:OSS 对 `/api/branding` 返回 **200 text/html**——`handlers/ui.go:64` 的 `/{filepath:*}` 兜底接住所有未注册路径,`serveDashboard`(:121-146)对无扩展名路径找不到文件时回退 `ui/index.html`。用 §6 自己的对照命令起 OSS 二进制实测:`/api/branding`、`/api/does-not-exist`、`/api/ee/ping` 均 `200 text/html 7138B`。断言应改为「OSS 对照 Content-Type 为 text/html(非 JSON)」或删掉 OSS 半句。
   - T5「`config.db` 的 plugins 表」:表名是 **`config_plugins`**(framework/configstore/tables/plugin.go:42 `TableName()`,`sqlite3 ~/.config/bifrost/config.db ".tables"` 亦为 `config_plugins`),列名 `name`。断言命令写成 `sqlite3 <app-dir>/config.db "select count(*) from config_plugins where name='ee-probe'"` 期望 `0`。
