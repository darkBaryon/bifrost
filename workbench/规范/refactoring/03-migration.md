# 3. 分期迁移、偏差与预飞

[← 上一章：方案与 Gate 1](02-plan-and-review.md) · [重构规范](README.md) · [下一章：复核与收口 →](04-review-and-cleanup.md)

## 分步迁移

开始前重新确认工作目录、分支、基线和未提交修改。业务项目的本机配置、凭据和生成环境不得进入重构提交。

实施时：

1. 按迁移顺序逐步执行；
2. 每一步保持可编译、可测试、可回滚；
3. 优先建立行为保护，再移动或替换结构；
4. 每步相关检查通过后形成可审阅 commit；
5. 只暂存属于本步的文件；
6. 记录步骤、commit、行为结果和偏差。

兼容层必须有明确退出条件。新旧结构并存只是迁移手段，不是默认终态。

## 偏差即停

目标结构、公共接口、调用方范围、迁移顺序、行为口径或验证方式变化都属于偏差；方案声明但没有实施的内容同样属于偏差。

| 级别 | 情形 | 动作 |
|---|---|---|
| 小偏差 | 迁移细节变化，目标结构和行为口径不变 | 记录原因和影响，交代码复核确认 |
| 中偏差 | 步骤、接口、范围或验证方式变化 | 停止迁移，修订方案，差量复核并由用户确认 |
| 大偏差 | 终态、行为假设或迁移策略被证伪 | 中止当前阶段，修订蓝图/方案并重新 Gate 1 |

不得先按新的理解完成，再补写“无偏差”。外部工具或环境故障需要记录复现、影响、替代核验和解除条件。

## 实施记录

- **实施记录**：步骤、commit、一句话说明和验收自查；
- **实施偏差记录**：计划外变化或漏做项，无则明确写“无”；
- **蓝图验证备忘**：分期任务记录接口表达力、关键假设和是否应修订蓝图。

交接必须落盘任务来源、范围、基线、当前版本、产物、检查结果、偏差、阻塞和下一 Gate，不能只依赖聊天上下文。

## 预飞自检

交代码复核前执行项目支持的机械检查：

- 格式、静态检查、全量或相关测试和构建；
- 旧符号和临时兼容层清理；
- 公共接口签名 diff 与白名单对账；
- 架构禁区和依赖方向；
- 重复代码和死代码扫描；
- 生成代码重建与零漂移；
- 实际 diff 与本期方案范围。

机械检查形成事实表。脚本不能证明结构合理或行为等价，这些判断留给独立复核。红项未处理、替代证据未说明或强制盲区未裁决时，不进入正式代码复核。

## 并行和分期边界

每条迁移线使用独立分支、Worktree 和实施上下文。共享公共契约先独立落地；改动足迹高度重叠时排队。上一期阻塞未关闭，不开始下一期实施。生成文件冲突由生成器重建，不手工拼接。
