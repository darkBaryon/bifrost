# 内容安全框架：假检测器开发联调

验证日期：2026-09-17。当前工作树包含代码阅读阶段的命名、文件拆分，以及本次开发用假检测器和应用装配；此记录是开发验证证据。

## 验证范围

通过 `EE_GUARDRAILS_FAKE` 显式选择场景，启动真实 EE HTTP 应用，在 `app` 注册插件。检测器匹配固定标记 `[guardrails-test]`，模型由本地 HTTP 服务回显消息。使用临时 SQLite、随机端口，不连接真实模型。

| 场景 | 结果 |
|---|---|
| 默认关闭 | 普通消息和标记消息均正常返回，流式请求成功 |
| 输入拦截 | 标记消息返回 HTTP 400 / `content_safety_blocked`，模型调用次数为 0；普通消息通过 |
| 输入仅记录 | 标记消息正常返回，日志包含 `action=observe` |
| 输出拦截 | 标记回答返回 HTTP 400 / `content_safety_blocked`，模型已调用一次，响应不含 `choices` |
| 输出规则 + 流式 | 返回 `content_safety_output_stream_unsupported`，模型调用次数为 0 |
| 关闭后重启 | 复用同一数据库，标记消息恢复正常返回，开发插件未持久化 |

执行 `python3 ee/scripts/guardrails-smoke.py` 全部通过。HTTP 日志保留在本机临时目录 `/var/folders/m3/56qrlvk11xs7nc4cxjnw1b700000gn/T/ee-guardrails-tb2juen1`。

## 前端验证

使用 Playwright 打开上述脚本的 `--serve input-block` 隔离环境，登录现有控制台，在“提示词仓库”的 Playground 新建提示词，选择 OpenAI / `guardrails-test-model`：

1. 发送普通消息，页面显示“本地模型替身：普通测试消息”。
2. 发送 `[guardrails-test]`，页面显示错误“开发测试：内容命中假检测器，已拦截”。

本机截图：[正常返回](../../output/playwright/guardrails-allow.png)、[命中拦截](../../output/playwright/guardrails-block.png)。截图是本地验证产物，不作为仓库源码提交。

假模型不在模型参数目录中，浏览器出现一次参数查询 404，Playground 使用默认参数后正常运行；拦截请求的 HTTP 400 符合预期。未修改上游前端。
