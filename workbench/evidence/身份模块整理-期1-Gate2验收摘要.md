## 重构对账

- **原行为 → 允许变化 → 实际**：对外 HTTP 契约、错误体、Cookie、`ee_identity_v1` 迁移与表结构、路由表、DTO 键集合全部未动（收敛评审 1 三方对账：`账号认证接口.md:13` = `dto.go` `accountDTO` = `dto_test.go` 断言）。唯一允许的变化 FIND-020：到期即删、含已撤销/已消费、不加索引、迁移 ID 不变，与 §4.6 拍板逐条一致；边界按评审 R5 从 `<` 改 `<=` 与业务判定同口径，代码评审 T3 复核无可观察差异（实施偏差 7）。
- **目标结构**：`identity` 根包零第三方依赖；`identity/{http,persistence,hasher}` 各适配一个库；`host` 只触及宿主对象；`app` 只装配。依赖图单向无环，收敛评审 1 按全量 import 图逐边核对。
- **调用方与公共接口**：删除 `identity.Service`/`NewService`/`Credential`、`persistence.Passwords`；新增 `Services`/`New`/三个服务类型/`AccountRecord`/`Account.CreatedAt`/`hasher.Bcrypt`；重命名与签名变化各项均在 §6 白名单；禁留 8 条全仓 0 命中。
