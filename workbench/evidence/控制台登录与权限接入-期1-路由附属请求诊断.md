# 控制台登录与权限接入：期1路由附属请求诊断

2026-09-23，基线 `d93fa8ad2082c716f76c55720b2272e718a7f649`，工作树 `bifrost-console-ui` / `feat/console-ui`。

## 目的与结论

验证“编辑器附属接口返回403，会导致只有 RoutingRules.View 的账号无法使用整个路由规则页面”这一先前推断。

**该推断在本次前端隔离实验中不成立。** 列表、分页、空状态和已检查的规则详情仍可用；附属请求确实发生并被拒绝，但未把本次页面重定向、替换为整页错误或显示业务错误 toast。团队名称读取失败会让详情缺少关联名称，当前也没有显示 scope_id 作为回退。

这不证明整个 EE 工作台已可用，不证明真实后端已经接入，也不证明编辑表单所有操作可用。不能用这条附属查询问题推导“隐藏其他现有页面”或“必须另建 RoutingRulePolicy”。

## 实验边界与构造

- 复制当前 `ui/` 到临时目录；真实路由 View、Table、EmptyState、Sheet、InfoSheet 与原文件 SHA256 一致。没有修改仓库业务源码。
- 使用原 Redux store、RTK Query API、baseQuery、TopbarProvider、实际 RoutingRulesView。最小 TanStack 路由承载页面，安装 Sonner Toaster。
- 只在临时副本的既有 `useRbac(resource, operation)` 入口提供模拟权限：RoutingRules.View=true，其余=false。不新增业务策略接口。
- EE/fallback baseQuery 保持透传；HTTP 均由只监听 `127.0.0.1:43179` 的 Vite fixture middleware 处理，不连接真实后端或业务数据库。未知 API 统一返回403。
- `GET /api/routing/rules` 返回合成规则或空列表，非空组26条、每页25条；`GET /api/providers`、`GET /api/keys`、`GET /api/governance/teams/fixture-team-1` 返回403及 `{error:{message:"forbidden (synthetic fixture)"}}`。
- **没有挂载真实 ClientLayout/Sidebar/Topbar 外壳，没有测试登录、真实权限接口、树视图、编辑提交、撤权、多标签或WS。** 外壳的 `/api/config` 问题不在这个实验范围内。

## 源码交叉核对

- `ui/app/workspace/routing-rules/views/routingRulesView.tsx` 已通过 `useRbac` 控制 Create/Update/Delete。其列表查询与编辑器附属查询独立。
- `routingRuleSheet.tsx:87–90` 的附属 queries 只取 data，默认空数组，不读取 error 并抛出到父页。
- `routingRuleInfoSheet.tsx:46–65` 查名失败后为 undefined，渲染时省略名称；没有相应 toast 或整页错误分支。
- `ui/lib/store/apis/baseApi.ts:82` 的普通403返回错误结果，不全局登出或toast；401是另一条路径。
- **外壳有不同的、已证实的阻断路径：** `ui/app/clientLayout.tsx:80` 读取完整config，`:95` 错误toast；`:184–191` 首次无config且请求失败时返回 ConfigUnreachable 而不渲染children。不能用本实验否认这个实际缺口。

## 对当前方案的影响

1. 保留用户已经使用的现有业务页面；按权限控制访问，不以缩减页面范围代替接入。
2. EE 实现已有 RBAC 接口并消费现有权限 matrix；不重建业务权限框架。
3. 撤回 RoutingRulePolicy、附加的整页编辑权限门槛、旧user scope禁止编辑等未获证明的设计。
4. 如果后续决定避免某条无权附属请求，优先验证在现有 useRbac + query skip 上最小修改是否足够；当前没有实施这样的修改。加载时机改变需单独说明，不能把加入 `!open` 说成 OSS 完全无行为变化。
5. 关联名称缺失是局部显示问题。编辑器的选项加载及保留旧引用提交等仍待诊断，不从只读实验外推。
6. bootstrap、账号菜单隔离、首页落点和通知生命周期等候选方案，继续以各自真实调用链核实必要性；本实验不为其统一背书。
