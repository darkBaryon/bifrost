# 收敛评审 Skill

本 skill 只是入口，规则与操作步骤以工作台规范为唯一权威，不在此复述：

1. 读 `workbench/规范/流程/收敛评审.md`（目的、输入、四维、出口、校准）。
2. 读 `workbench/规范/流程/收敛评审审查方向.md`（工作程序、起手表每行必执行、意见写法、开放式复读）。
3. 读 `workbench/规范/项目/编码规范.md`（本项目"同类实现约定"的参照物）。
4. 用 `workbench/templates/收敛评审提示词.md` 填好参数后执行；产物按 `workbench/templates/收敛评审.md` 落盘，verdict 写入 frontmatter。

范围：只管像不像、乱不乱（重复 / 职责与实现质量 / 架构与项目一致性 / 契约一致性）。正确性、测试、非功能归代码评审，看到只写一行「转代码评审」。评审者与实施上下文隔离，只出意见不改代码。
